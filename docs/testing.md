# Checklist de pruebas manuales

- [ ] Instalar dependencias desde la raíz.
- [ ] `npm run build` termina sin errores.
- [ ] La pantalla inicial funciona en escritorio y móvil.
- [ ] Un jugador crea una sala y recibe un código.
- [ ] Un segundo navegador entra con ese código.
- [ ] El lobby muestra ambos jugadores y solo el anfitrión inicia.
- [ ] Cada jugador recibe su propio fragmento de pista.
- [ ] Mensajes de chat llegan a todos los participantes.
- [ ] Respuesta incorrecta no cambia el módulo.
- [ ] Respuesta correcta avanza el módulo en todos los clientes.
- [ ] Temporizador sincronizado termina en derrota.
- [ ] El equipo puede ganar y reiniciar.
- [ ] Desconexión del anfitrión asigna un nuevo anfitrión.
- [ ] La URL pública funciona en un dispositivo externo.
